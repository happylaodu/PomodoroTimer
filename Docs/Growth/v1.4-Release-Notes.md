# 🎉 Version 1.4 - Chinese Localization & Quality Improvements

## 🌍 New Features

### Full Chinese Localization
- **Complete Simplified Chinese (简体中文) support**
- Automatic language switching based on system preferences
- All UI elements, menus, and notifications localized
- Chart labels display in user's preferred language

### Launch at Login
- **New option to start automatically when computer starts**
- Easy toggle in Settings panel
- User-friendly text: "Start automatically when computer starts"
- Integrated seamlessly with Auto Start Control section

### Sound Customization
- **Choose from 12 different notification sounds**
- Preview sounds instantly when selecting
- Option to disable sound completely
- Sounds: Ping, Glass, Hero, Tink, Purr, Basso, Blow, Bottle, Frog, Funk, Pop, Sosumi

### Global Keyboard Shortcuts
- **Control the timer from any application**
- Show Window: `⌘⇧T` - Quick access to main window
- Start/Pause: `⌘⇧P`
- Reset: `⌘⇧R`
- Switch Mode: `⌘⇧M`
- Shortcuts displayed in Settings panel

## 🐛 Bug Fixes

### Timer Synchronization
- Fixed menubar and main window countdown being out of sync
- Fixed timer continuing to count down after app quit
- Menubar time display now uses monospaced font to prevent icon jumping

### Chart Improvements
- Fixed chart date labels not displaying in Chinese
- Optimized chart layout and spacing
- Improved date label positioning for better alignment
- Larger chart window (360x220) for better visibility
- Fixed progress ring animation glitches

### Settings Window Improvements
- Fixed toggle controls appearing gray on first open
- Increased window height for better spacing
- Improved window activation and visibility

## 🎨 UI Improvements
- Better visual alignment in statistics chart
- Smoother countdown display updates
- More stable menubar appearance
- Enhanced overall user experience
