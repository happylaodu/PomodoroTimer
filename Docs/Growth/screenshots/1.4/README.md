## 📋 使用步骤

### 1. 准备实际截图
在对应语言环境下运行应用，截图保存为：

**英文版（已完成）：**
- `work-time.png` ✅
- `settings.png` ✅
- `rest-time.png` ✅
- `chart.png` ✅

**中文版（待截图）：**
- `work-time-zh.png`
- `settings-zh.png`
- `rest-time-zh.png`
- `chart-zh.png`

### 2. 生成App Store截图
1. 用浏览器打开对应的HTML文件
2. 点击"隐藏提示，准备截图"按钮
3. 按 `Cmd+Shift+4`，然后按空格键
4. 点击浏览器窗口完成截图（1280x800）

### 3. 上传到App Store Connect
- 英文版：上传到 `English (U.S.)` 语言
- 中文版：上传到 `Simplified Chinese` 语言
- 尺寸要求：1280x800 或更高分辨率
