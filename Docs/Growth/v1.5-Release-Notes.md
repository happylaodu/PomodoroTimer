```markdown
# 🎉 Version 1.5 - Statistics Export & Enhanced User Experience

## 📊 New Features

### Statistics Export
- **Export your Pomodoro data for analysis and reporting**
- **CSV Export**: Download all your session data in spreadsheet format
  - Columns: Date, Sessions, Cumulative Total
  - Perfect for Excel, Google Sheets, or data analysis tools
- **PDF Reports**: Generate professional reports with summary statistics
  - **Weekly Report**: Last 7 days of activity
  - **Monthly Report**: Last 30 days of activity
  - **All-Time Report**: Complete session history
- **Report Features**:
  - Professional layout with titles and timestamps
  - Summary statistics (total sessions, days tracked, average per day, most productive day)
  - Daily breakdown table with dates and session counts
  - Automatic file naming with date stamps

### Improved First Launch Experience
- **Auto-show main window on first launch**
  - Helps new users find the menu bar icon immediately
  - No more confusion about where the app went
- **"Launch at Login" now defaults to ON**
  - Improves user retention by keeping app accessible
  - Users are less likely to forget about the app
  - Can be disabled anytime in Settings

## 🐛 Bug Fixes

### File Access
- Fixed sandbox entitlements for save dialogs
- Export dialogs now appear properly above Settings window

### Window Management
- Removed floating window level from Settings
- Save dialogs no longer hidden behind Settings window

### PDF Generation
- Fixed upside-down text rendering in PDF reports
- Correct coordinate system handling for macOS

## 🎨 UI Improvements

### Settings Panel
- New "📊 Statistics Export" section
- Four export buttons with bordered style:
  - Export to CSV
  - Weekly Report (PDF)
  - Monthly Report (PDF)
  - All-Time Report (PDF)
- Settings window height increased to 780px for better layout
- Better visual organization of export options

## 🌍 Localization

### Full Bilingual Support
- All new features fully localized:
  - English: "Statistics Export", "Export to CSV", "Weekly Report (PDF)", etc.
  - Chinese: "统计数据导出", "导出为 CSV", "每周报告（PDF）", etc.
```
