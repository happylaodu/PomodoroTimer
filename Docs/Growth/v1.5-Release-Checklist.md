## 🚀 App Store Release

### 1. Archive Build
```bash
# In Xcode:
Product → Archive

# Or command line:
xcodebuild archive \
  -project PomodoroTimer.xcodeproj \
  -scheme PomodoroTimer \
  -archivePath ~/Desktop/PomodoroTimer-v1.5.xcarchive
```

### 2. Upload to App Store
1. Xcode → Window → Organizer
2. Select Archive
3. Distribute App → App Store Connect
4. Upload (wait 10-30 minutes for processing)

### 3. App Store Connect Configuration
Visit: https://appstoreconnect.apple.com

**Steps:**
1. My Apps → Pomodoro Timer Lite
2. Create new version `1.5`
3. Fill in "What's New" (see below)
4. Wait for build processing
5. Select build version 1.5
6. Submit for review
