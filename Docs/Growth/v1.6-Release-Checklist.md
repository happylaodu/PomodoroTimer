## 🚀 App Store Release

### 1. Update Version Number
```bash
# In Xcode:
# 1. Select project in navigator
# 2. Select target "PomodoroTimer"
# 3. General tab → Identity
# 4. Version: 1.6
# 5. Build: 16 (or increment from v1.5)
```

### 2. Create App Store Screenshots
```bash
# See: Docs/Growth/screenshots/1.6/README.md

Required screenshots (5 total):
1. Work Time - Main interface
2. Achievements - NEW: Dual-tab window (Badges + Statistics) ⭐ CORE FEATURE
3. Settings - UPDATED: Achievements at top
4. Chart - In-app productivity chart
5. PDF Export - Professional reports

Priority: Create Achievements screenshot first (main selling point)
```

### 3. Archive Build
```bash
# In Xcode:
Product → Archive

# Or command line:
xcodebuild archive \
  -project PomodoroTimer.xcodeproj \
  -scheme PomodoroTimer \
  -archivePath ~/Desktop/PomodoroTimer-v1.6.xcarchive
```

### 4. Upload to App Store
1. Xcode → Window → Organizer
2. Select Archive
3. Distribute App → App Store Connect
4. Upload (wait 10-30 minutes for processing)

### 5. App Store Connect Configuration
Visit: https://appstoreconnect.apple.com

**Steps:**
1. My Apps → Pomodoro Timer Lite
2. Create new version `1.6`
3. Fill in "What's New" (see below)
4. Wait for build processing
5. Select build version 1.6
6. Submit for review
