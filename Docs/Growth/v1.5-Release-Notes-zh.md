# v1.5 中文版本说明

## 🎉 版本 1.5 - 统计数据导出与用户体验提升

### 📊 新功能

**统计数据导出**
- 将番茄钟数据导出用于分析和报告
- **CSV 导出**：下载所有会话数据为电子表格格式
  - 列：日期、会话数、累计总数
  - 适用于 Excel、Google Sheets 或数据分析工具
- **PDF 报告**：生成专业的统计报告
  - **每周报告**：最近 7 天的活动
  - **每月报告**：最近 30 天的活动
  - **总体报告**：完整会话历史
- **报告功能**：
  - 专业排版，包含标题和时间戳
  - 汇总统计（总会话数、跟踪天数、每天平均、最高效的一天）
  - 每日明细表，包含日期和会话计数
  - 自动文件命名，带日期戳

**改进首次启动体验**
- 首次启动自动显示主窗口
  - 帮助新用户立即找到菜单栏图标
  - 不再困惑应用在哪里
- "登录时启动"现在默认开启
  - 保持应用可访问，提高用户留存
  - 用户不容易忘记应用
  - 可随时在设置中关闭

### 🐛 问题修复

- 修复了沙箱权限，支持保存对话框
- 导出对话框现在正确显示在设置窗口上方
- 移除了设置窗口的浮动级别
- 修复了 PDF 报告中文本倒置的问题

### 🎨 界面改进

- 设置面板新增"📊 统计数据导出"部分
- 四个导出按钮：
  - 导出为 CSV
  - 每周报告（PDF）
  - 每月报告（PDF）
  - 总体报告（PDF）
- 设置窗口高度增加至 780px，布局更好
