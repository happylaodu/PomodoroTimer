## 📋 待办事项

### App Store发布

#### 1. Archive构建
```bash
# 在Xcode中：
Product → Archive

# 或命令行：
xcodebuild archive \
  -project PomodoroTimer.xcodeproj \
  -scheme PomodoroTimer \
  -archivePath ~/Desktop/PomodoroTimer-v1.4.xcarchive
```

#### 2. 上传到App Store
1. Xcode → Window → Organizer
2. 选择Archive
3. Distribute App → App Store Connect
4. 上传（等待10-30分钟处理）

#### 3. App Store Connect配置
访问: https://appstoreconnect.apple.com

**步骤：**
1. 我的App → Pomodoro Timer Lite
2. 创建新版本 `1.4`
3. 填写"此版本新增内容"（见下方）
4. 等待构建处理完成
5. 选择构建版本 1.4 (6)
6. 提交审核
