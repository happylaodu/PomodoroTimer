# 🎉 版本 1.4 - 中文本地化及品质提升

## 🌍 新功能

### 完整中文本地化
- **全面支持简体中文**
- 根据系统语言自动切换
- 所有界面元素、菜单和通知均已本地化
- 图表标签根据用户语言显示

### 开机自启动
- **新增"开机时自动启动"选项**
- 在设置面板中轻松切换
- 使用通俗易懂的文字描述
- 完美集成到自动启动控制区域

## 🐛 问题修复

### 计时器同步优化
- 修复菜单栏与主窗口倒计时不同步的问题
- 修复退出应用后计时器仍在运行的问题
- 菜单栏时间显示采用等宽字体，消除图标跳动

### 图表改进
- 修复图表日期标签未显示中文的问题
- 优化图表布局和间距
- 改进日期标签位置，更好对齐柱状图
- 增大图表窗口尺寸（360x220），视觉效果更佳
- 修复进度圆环动画异常问题

### 设置窗口优化
- 修复首次打开时开关显示为灰色的问题
- 增加窗口高度，改善底部间距
- 优化窗口激活和显示逻辑

## 🎨 界面优化
- 统计图表视觉对齐更精准
- 倒计时显示更新更流畅
- 菜单栏显示更稳定
- 整体用户体验提升
