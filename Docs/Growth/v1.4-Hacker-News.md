## 💬 Common Questions & Responses

### Q: Why Mac only?
```
I'm a Mac developer and wanted to build something truly native for macOS first.
The goal was to create the lightest, most privacy-focused timer possible using
platform-specific APIs. May consider other platforms based on feedback!
```

### Q: How is it so small?
```
- No third-party dependencies
- Native frameworks only (SwiftUI, AppKit, Charts)
- No bundled assets beyond system icons (SF Symbols)
- Efficient data structures
- No analytics, ads, or cloud sync libraries

The final .app is 1.7MB uncompressed. Most timer apps include analytics SDKs,
ad frameworks, and cloud sync which easily add 10-20MB.
```

### Q: Will it stay free?
```
Yes! It's MIT licensed and open source. No plans for subscriptions or premium
features. I built this to solve my own problem and wanted to share it with the
community.
```

### Q: How do keyboard shortcuts work?
```
They use NSEvent.addGlobalMonitorForEvents to register system-wide hotkeys.
Works from any application:
- ⌘⇧T: Show window
- ⌘⇧P: Start/Pause
- ⌘⇧R: Reset
- ⌘⇧M: Switch mode (work/rest)

All shortcuts are displayed in the Settings panel.
```

### Q: Why SwiftUI instead of AppKit?
```
I used a hybrid approach - SwiftUI for the UI (modern, declarative) and AppKit
for menu bar integration (NSStatusItem) and global hotkeys. SwiftUI made the
charts and animations much easier to implement while keeping the bundle size small.
```

### Q: What about iOS version?
```
Considered it, but menu bar integration is a core feature. On iOS, it would need
a different UX paradigm. The keyboard shortcuts wouldn't translate either. Open
to suggestions on how it should work on mobile!
```

### Q: Any plans for [feature X]?
```
Thanks for the suggestion! I'm keeping a list of feature requests on GitHub.
The goal is to stay minimal and fast, but I'm definitely open to improvements.
Feel free to open an issue!
```

### Q: How does Chinese localization work?
```
Full i18n support using Xcode's localization system (en.lproj + zh-Hans.lproj).
The app automatically switches language based on system preferences. All UI
elements, notifications, and chart labels are localized.
```
