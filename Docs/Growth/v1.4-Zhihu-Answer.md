❌ 不用 Electron（+30MB）
❌ 不用 React Native（+20MB）
❌ 不用 Firebase Analytics（+10MB）
❌ 不用广告 SDK（+8MB）
❌ 不用第三方 UI 库

✅ 纯原生 SwiftUI
✅ SF Symbols（系统自带图标）

## 🎯 v1.4 技术亮点

### 全局快捷键实现
```swift
NSEvent.addGlobalMonitorForEvents(matching: .keyDown) { event in
    if event.modifierFlags.contains([.command, .shift]) {
        switch event.keyCode {
        case 35: // P key - Start/Pause
            toggleTimer()
        case 17: // T key - Show window
            showWindow()
        // ...
        }
    }
}
```

### 多语言支持
使用 Xcode 原生本地化：
- `en.lproj/Localizable.strings`
- `zh-Hans.lproj/Localizable.strings`
- 根据 `Locale.current.language` 自动切换

### 菜单栏同步优化
v1.4 修复了菜单栏与主窗口倒计时不同步的问题：
- 使用统一的 Timer Publisher
- 菜单栏采用等宽字体（消除数字跳动）
- 优化刷新频率
