## How to Use New Features

### Exporting Statistics

1. Click the **Settings** gear icon in the main window
2. Scroll to **📊 Statistics Export** section
3. Choose your export format:
   - **Export to CSV**: Raw data for spreadsheet analysis
   - **Weekly Report (PDF)**: Last 7 days with daily chart
   - **Monthly Report (PDF)**: Last 30 days with daily + weekly charts
   - **All-Time Report (PDF)**: Complete history with comprehensive charts
4. Select save location and filename
5. Done! Your report is ready to view or share

### Understanding the Charts

**Daily Activity Chart (Blue)**:
- Shows number of Pomodoro sessions completed each day
- X-axis: Dates (MM/DD format)
- Y-axis: Session count
- Values displayed on top of each bar

**Weekly Overview (Green)** - Monthly/All-Time only:
- Aggregates sessions by week (Sunday - Saturday)
- Helps identify weekly patterns and trends
- Week labels show the Sunday date of each week
