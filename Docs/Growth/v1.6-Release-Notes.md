# v1.6 Release Notes

## 🎉 Version 1.6 - Achievement System & Motivation

### 🏆 New Features

**Achievement System**
- Brand new achievement system to make focus more rewarding
- **9 Achievement Badges**:
  - **Session-Based Achievements**:
    - 🌱 First Focus - Complete your first pomodoro session
    - 🔰 Getting Started - Complete 10 pomodoro sessions
    - 💪 Dedicated - Complete 50 pomodoro sessions
    - 💯 Centurion - Complete 100 pomodoro sessions
    - 🎯 Master of Focus - Complete 500 pomodoro sessions
    - 👑 Legend - Complete 1000 pomodoro sessions
  - **Streak-Based Achievements**:
    - 📅 Week Warrior - Use the app for 7 consecutive days
    - 🗓️ Monthly Master - Use the app for 30 consecutive days
    - 🏅 Consistency Champion - Use the app for 100 consecutive days

**Achievement Interface**
- Achievement progress displayed at the top of settings panel
  - Eye-catching orange unlock count: "Unlocked: 6/9"
  - Prominent "View All" button
- Dedicated achievement window (500×600)
  - Grid layout showing all achievements
  - Current streak display
  - Color for unlocked, grayscale for locked achievements
  - Each achievement shows title, description, requirement, and unlock date

**Smart Migration**
- Automatically analyzes historical data to unlock earned achievements
- Correctly calculates historical streak from past usage
- Accurate current streak calculation from last used date to today

### 🐛 Bug Fixes

- Fixed streak calculation algorithm
  - Correctly calculates consecutive days from historical data to today
  - Fixed incorrect streak display after migration
- Fixed historical data migration issues
  - Completed sessions automatically unlock corresponding achievements
  - Historical streaks are correctly recognized

### 🎨 Interface Improvements

- Achievements moved to the top of settings panel
  - More prominent position for better user engagement
  - Orange highlighted text, blue prominent button
- Settings window height increased to 900px
  - Less scrolling, better browsing experience
  - More settings visible at once

### 🌍 Localization

- Full bilingual support (English & Chinese)
  - All achievement titles and descriptions
  - Interface text
  - Streak display format

### 🔧 Technical Details

- **Zero third-party dependencies**: Native SwiftUI and Foundation only
- **Local storage**: UserDefaults + JSON encoding
- **App size**: Still lightweight (~1.7MB)
- **System requirements**: macOS 13.0+
